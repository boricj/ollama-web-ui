# Ollama Web UI

> [!CAUTION]
> Vibe-coded.

A lightweight, single-page web chat interface for Ollama that stores user data in the browser.

## Installation

Serve `www/` behind a reverse proxy to an Ollama API.

## Development

Use `caddy` and the example Caddyfile to serve the web app locally against an Ollama server.

> [!WARNING]
> This is a plain HTML5/CSS/JavaScript project.
> There's no `npm`, `npx` or whatever web dev cancer is trendy these days.
